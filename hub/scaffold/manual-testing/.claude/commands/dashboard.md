Start the local web dashboard for this project.

Run in background:
```bash
python web/app.py
```

Then tell the user:
- Dashboard is running at http://localhost:8080
- Browser should open automatically
- Press Ctrl+C in the terminal to stop

If port 8080 is already in use, suggest they check if a previous instance is running, or open http://localhost:8080 directly in the browser.
