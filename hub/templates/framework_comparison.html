1. Component scaffold

Vue 3 (Options API)const App = { data() { return { bugs: [], filter: '' }; }, computed: { filteredBugs() { return this.filter ? this.bugs.filter(b => b.severity === this.filter) : this.bugs; }, }, methods: { async loadBugs() { /* ... */ }, }, mounted() { this.loadBugs(); }, }; Vue.createApp(App).mount('#app');
React 19 (hooks)function App() { const [bugs, setBugs] = useState([]); const [filter, setFilter] = useState(''); const filteredBugs = useMemo( () => filter ? bugs.filter(b => b.severity === filter) : bugs, [bugs, filter] ); useEffect(() => { loadBugs(); }, []); // ... } ReactDOM.createRoot(el).render(<App />);

2. Two-way binding (form input)

Vue 3 — v-model<input v-model="form.title">
React 19 — controlled input<input value={form.title} onChange={e => setForm({ ...form, title: e.target.value })} />

3. List rendering with key

Vue 3<tr v-for="(b, i) in filteredBugs" :key="b.id"> <td>{{ i + 1 }}</td> <td><b>{{ b.title }}</b></td> </tr>
React 19{filteredBugs.map((b, i) => ( <tr key={b.id}> <td>{i + 1}</td> <td><b>{b.title}</b></td> </tr> ))}

4. Conditional render

Vue 3 — v-if / v-else-if / v-else<div v-if="loading">Loading…</div> <div v-else-if="!filteredBugs.length">No bugs.</div> <table v-else> ... </table>
React 19 — ternary chain{loading ? ( <div>Loading…</div> ) : filteredBugs.length === 0 ? ( <div>No bugs.</div> ) : ( <table> ... </table> )}

5. Dynamic class binding

Vue 3 — :class binding<span class="sev" :class="b.severity" >{{ b.severity }}</span>
React 19 — template string<span className={`sev ${b.severity}`} >{b.severity}</span>

Quantitative comparison (this exact PoC)

Vue 3 React 19

JS for the same component ~70 lines ~95 lines (~35% more)
Bundle from CDN vue.global.prod.js — 1 file (~98 KB) react + react-dom + babel — 3 files (~1.2 MB with babel)*

Reactivity model Auto — change this.x Explicit — call setX
